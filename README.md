# 4cm メンズ曲がる縮毛矯正LP

金沢・野々市のメンズ曲がる縮毛矯正をご紹介する静的ランディングページです。

正規URL：https://magaru.4cm.jp/

## 構成

- index.html：トップページ、FAQ、予約リンク、構造化データ
- assets/：CSS、配信サイズ別の画像、アイコン、SNS共有画像
- robots.txt・sitemap.xml：検索向け設定
- _redirects・_headers：Netlifyの転送・キャッシュ設定
- 404.html：見つからないページの案内
- googlece06e2665a48e679.html：Google所有権確認ファイル

インストール・ビルドは不要です。index.htmlと同じ階層のassets等をまとめて配信します。

Netlifyへの本番反映は、確認後に手動で行います。このリポジトリには受領元写真、バックアップ、作業メモ、認証情報、ZIPは含めていません。
